О себе

Четыре роли — одна логика

4 года в IT и 4 года преподавания истории — это два разных опыта, и я их не смешиваю. Начинал с обучения пользователей и сопровождения ключевых клиентов, затем добавил инженерию данных и магистратуру по ИИ, а педагогику продолжил уже в ИТ. Выберите роль — покажу, что умею именно в ней.

Собираю данные в работающие пайплайны

Проектирую ETL-процессы: от CSV и Excel через трансформации на Python до загрузки в PostgreSQL и витрин для BI. Разбираюсь в моделях «звезда», «снежинка» и Data Vault, пишу сложный SQL и настраиваю оркестрацию в Apache Airflow.

  • ETL-пайплайны на Python + PostgreSQL, оркестрация и мониторинг DAG в Apache Airflow
  • Сложный SQL: оконные функции, CTE, JOIN, подзапросы; оптимизация запросов
  • Моделирование данных и витрины для аналитики: звезда, снежинка, Data Vault
  • Дашборды в Yandex DataLens, работа в Git, Docker и Linux
  • Теоретическая база Big Data: Hadoop (HDFS, MapReduce), Spark (SQL, Streaming), Kafka
